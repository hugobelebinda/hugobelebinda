# 💫 About Me:
Software Engineer focused on building robust and secure backend infrastructure. Currently a Software Engineering student at Concordia University (Co-op) with a deep interest in scalable system design.<br><br>I’ve learned that the true measure of a backend isn't just that it works, but how it handles the weight of real-world data. This mindset drove the development of ScriptureGraph, where I architected a containerized PostgreSQL environment in Docker to manage over 615,000 records. By implementing stream-based ETL pipelines in TypeScript and optimizing B-Tree indexes for sub-second retrieval, I focused on ensuring the system remains stable and performant under significant load.<br>From implementing secure OAuth 2.0 flows with server-side token exchange to managing complex data migrations, I prioritize building services that are secure by default and architected to prevent failure.<br><br>My Technical Toolkit:<br>Languages & Runtimes: TypeScript, Node.js, SQL (PostgreSQL), Java.<br>Data & Infrastructure: Docker (Containerization), Prisma, Supabase, and Git.<br>Core Competencies: API Architecture, Secure Data Persistence, and ETL Pipeline Development.
